# InfineCode Tech Internship Projects

This repository contains three full-stack web applications developed as part of the InfineCode Tech internship. These projects demonstrate a progression of skills in frontend and backend development, focusing on responsive UI design, database management, API development, and building practical software solutions.

## Projects Overview

### 1. [Employee Management System (EMS)](./Employee%20Management%20System)
A comprehensive, enterprise-grade Employee Management System designed to digitize and automate core HR processes. Built with a modern React frontend and a lightweight, high-performance native PHP backend, this system manages the complete employee lifecycle from recruitment to payroll, attendance tracking, and performance reviews.

### 2. [Event Management Portal](./Event%20Management%20Portal)
A full-stack, responsive web application designed for Non-Governmental Organizations (NGOs) to manage volunteer profiles, plan community drives/campaigns, track registrations, and monitor impact analytics. It features an interactive capacity tracker and simulated Role-Based Access Control (RBAC) for NGO Administrators and Volunteers.

### 3. [Student Task Manager](./Student%20Task%20Manager)
A clean, focused student task tracker to stay on top of assignments and deadlines. It features a lightweight, distraction-free UI, quick add/edit workflows, status filtering, and simple progress stats—perfect for daily study plans and project organization.

## Key Technologies Used
Across these projects, various technologies were utilized including:
- **Frontend**: React.js, Tailwind CSS, Vite
- **Backend**: PHP (REST APIs)
- **Database**: MySQL
- **Other Tools**: JWT Authentication, Postman
