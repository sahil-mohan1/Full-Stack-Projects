# Student Task Manager

Stay on top of assignments and deadlines with a clean, focused student task tracker. Add tasks quickly, filter them by status, and keep your workload organized at a glance.

Perfect for daily study plans, group projects, and exam prep.
Designed to keep things calm, clear, and easy to use.

## Highlights

- Quick add and edit flow for tasks
- Clear status filtering (All, Pending, Completed)
- Simple stats so you can track progress
- Lightweight, distraction-free UI

## Best For

- Students managing multiple subjects
- Anyone who wants a simple, no-clutter task list

## Run It Locally

```
npm install
npm run dev
```

## Notes

- `node_modules` is already ignored by Git via `.gitignore`.
- Remove build output before committing if needed.

If you want new sections like priorities, reminders, or due dates, just say the word.
